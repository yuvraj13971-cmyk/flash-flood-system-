About This Prototype

This is a college demonstration prototype (SIH-style project). It shows a complete flow: environmental data → preprocessing → ML models → FastAPI backend → this dashboard.

  • All training data is synthetic, generated to look realistic, not real sensor readings.
  • Model accuracy figures are computed by actually evaluating each model — nothing is hard-coded.
  • The LSTM module was trained on a small synthetic sequence dataset and is explicitly a proof-of-concept, not a validated time-series model.
  • Map locations use real Assam district names/coordinates from NRSC/ISRO's June 2022 flood report, but the rainfall/water-level/risk values shown for them are demo/simulated, not live sensor feeds.
  • The "2022 Reference" page shows real historical satellite-derived flood inundation data for context — it is a past event, not a live feed, and not the same kind of measurement as the ML model inputs.
  • No SMS/email alerts are sent — alerts are shown inside the app only.
  • This tool does not replace official disaster-management advisories.
